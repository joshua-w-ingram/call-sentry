# Changelog

## 1.4 (2026-09-10)

- First public release, under the name Call Sentry.
- Rule: rings for contacts, anyone you called or answered, anyone you texted. Everything
  else is rejected before it rings and lands in voicemail.
- Allow / Disallow overrides per number from the app screen.
- Every blocked call listed with the caller-ID name the network sent and how many times
  it tried.
- No network permission. Nothing leaves the phone.
- New icon.
